## What this does

Scaffoldet das Atlas-Frontend-Projekt: Next.js mit TypeScript + App Router (Desktop,
Frontend ist Prioritaet). Fuegt Drizzle ORM gegen Neon (serverless Postgres) hinzu:
`src/db/index.ts` baut den Drizzle-Client aus `@neondatabase/serverless` + `DATABASE_URL`.
`src/db/schema.ts` ist die kuenftige Heimat der Tabellen (T02 fuellt SchoolBlock/Routine/
ManualEvent). `drizzle.config.ts` zeigt drizzle-kit auf das Schema + die Migrations.
`drizzle-kit generate` erzeugt eine erste (leere) Migration, ohne DB-Verbindung.

Externe Abhaengigkeit (User): Neon-Projekt anlegen, `DATABASE_URL` in `.env.local`
eintragen. Erst dann verbindet die DB real (relevant ab T02/T04).
