# M001-S02-T03 -- Task Plan

**Summary:** Freie-Luecken-Berechnung: aus belegten Bloecken (Schule ohne cancelled +
feste Routinen + manuelle Events) die FreeSlots eines Tages / der Woche ableiten.

## Files

- Create: `lib/calendar-freeslots.ts` -- reine Slot-Logik. Typ `FreeSlot`
  {date, startTime, endTime, minutes}, Optionen {dayStart, dayEnd, minMinutes}
  (Defaults 06:00 / 22:00 / 15). `freeSlotsForDay(events, date, opt)` (pure),
  `attachFreeSlots(range, opt)` haengt pro Tag `freeSlots` an einen ExpandedRange.
- Modify: `app/api/calendar/route.ts` -- jeden Tag um `freeSlots` ergaenzen
  (aus bereits expandierten Daten, kein zusaetzlicher DB-Hit); Optionen via
  `?dayStart=&dayEnd=&min=` ueberschreibbar.

## What this does

Pro Tag: Busy-Intervalle = school_blocks mit status != cancelled (cancelled = frei) +
manuelle Events + feste Routinen (offene Routine endTime=null -> busy bis dayEnd).
Zeiten -> Minuten, auf [dayStart, dayEnd] geclippt, ueberlappende/anliegende Intervalle
gemmerged. FreeSlots = Luecken zwischen den gemergten Busy-Intervallen innerhalb des
Fensters, gefiltert auf `>= minMinutes`. Eine ausgefallene Untis-Stunde erzeugt so
automatisch eine freie Luecke.
