# M001-S03-T01 -- Task Plan

**Summary:** Wochenkalender-Ansicht (Desktop, design-first). SchoolBlocks + Routinen +
manuelle Events im Zeit-Raster, Entfall/Vertretung visuell markiert, freie Luecken
sichtbar, Jetzt-Linie. Dark/Light-Theme ("beides") mit Umschalter.

## Files

- Modify: `app/layout.tsx` -- next/font (Fraunces / Hanken Grotesk / JetBrains Mono als
  CSS-Variablen), antialiased, No-Flash-Theme-Script, metadata.
- Modify: `app/globals.css` -- Design-Tokens beider Themes (data-theme=light|dark),
  Reset, Atmosphaere (dezente Grain/Radials).
- Modify: `app/page.tsx` -- Client-Wochenkalender: fetch /api/calendar?view=week&date=,
  7-Spalten-Zeitraster 06-22, Event-Bloecke (school/routine/manual farbcodiert,
  cancelled hohl+gestrichelt "Entfall", substituted markiert), freie Luecken als
  Schraffur, Lane-Packing bei Ueberlappung, Jetzt-Meridian (today, live), Wochen-Nav
  (zurueck/Heute/vor), Theme-Toggle, flexible Ziele als Pills.
- Create: `app/week-calendar.module.css` -- Grid/Event/Toggle-Styles.

## What this does

Aesthetik: kartografischer Almanach. Concentric Radii, tabular-nums fuer Zeiten,
staggered Reveal der Tagesspalten, scale(0.96) on press, Shadows statt harter Borders,
keine `transition: all`. Theme in localStorage, kein FOUC.
