## What this does

**Plus-Button + Layout.** Kopf oben rechts: Datum/Label nach links, ganz rechts ein
Plus-Button (Primary, dezent). Daneben ein Refresh-Button (RefreshCw-Icon), der
POST /api/sync/untis ruft und danach den Kalender neu laedt (Spin waehrend Sync).

**Sheet (von rechts).** Klick auf Plus -> Sheet gleitet von rechts rein (framer-motion,
EASE = [0.22,1,0.36,1]), Backdrop dimmt. Oben Segmented Control "Einmalig | Woechentlich".
Felder: Name (autofocus), Von-Bis (Time-Wheel), Farbe (Palette), Ort, Notiz, Ganztag
(kleiner Schalter unten, bewusst un-prominent). Bei "Einmalig" zusaetzlich Datum; bei
"Woechentlich" Wochentag-Auswahl (Mo-So Chips). Submit -> POST /api/events (einmalig)
oder /api/routines mit type:fixed (woechentlich). Schliesst + Kalender-Reload.

**Time-Wheel.** Zwei Spalten (Std 00-23, Min im 5-Schritt) je fuer Von und Bis,
klick/scroll-tippbar, tabular-nums. Default: Start naechste volle Stunde, Ende +1h.

**Farb-Palette.** ~8 grosse, satte OKLCH-Swatches. Auswahl: weicher Spring-Scale +
Ring + Haken auf dem gewaehlten. Kein `<input type=color>`. Gewaehlte Farbe wird als
Hex/Token gespeichert und treibt den Block-Look (Rand 6px + Fuellung, hell/dunkel).

**Edit/Delete.** Klick auf einen eigenen Block (source manual|routine) oeffnet dasselbe
Sheet vorbelegt; "Speichern" -> PATCH, "Loeschen" -> DELETE (mit kurzer Bestaetigung).
Schulstunden (source school) bleiben read-only (kein Klick-Edit).

**Ganztag-Render.** allDay-Events erscheinen nicht im Zeitraster, sondern als schmaler
farbiger Balken am Kopf des jeweiligen Tages (Woche) bzw. oben in der Tages-Agenda.

Failure: leerer Name -> Submit disabled; Ende <= Start -> Inline-Hinweis; API-Fehler ->
kurze Fehlerzeile im Sheet, Sheet bleibt offen.
