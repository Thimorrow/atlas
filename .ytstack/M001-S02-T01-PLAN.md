## What this does

Routine-Validierung (`parseNewRoutine`): `title` non-empty; `type` in
{fixed, flexible_goal}; bei `fixed` -> `weekday` 0..6 + `startTime`/`endTime` (HH:MM[:SS]),
`openEnded` optional bool; bei `flexible_goal` -> `targetPerWeek` >= 1; `color` optional.
ManualEvent-Validierung (`parseNewManualEvent`): `title` non-empty, `date` (YYYY-MM-DD),
`startTime`/`endTime` (HH:MM[:SS]), `notes` optional. Patch-Parser validieren nur die
gesetzten Felder.

Routen: `nodejs` runtime, `force-dynamic`. POST -> 201 + erzeugte Row; ungueltiger Body
-> 400 + `{error}`. GET -> `{routines|events: [...]}`. PATCH -> 200 + Row bzw. 404 wenn
id fehlt. DELETE -> 200 `{deleted:true}` bzw. 404. Store-Funktionen nutzen
`returning()` und setzen `updatedAt: now()` beim Update.
