# M002-S04-T01 -- Range-Endpoint + subtiler Todo-Einweb im Kalender

**Summary:** Aufgaben subtil in beide Kalender-Ansichten einweben (Heute-Agenda +
Wochen-Raster), inkl. Range-Daten und Inline-Abhaken.

## Files

- Modify: `lib/todo-expand.ts` -- `getRangeView(startISO, endISO)` + `buildDayConcrete`
  Helper (nur konkret terminierte Instanzen pro Tag: dueDate===Tag oder RRULE-Vorkommen;
  done-Zustand fuer den Tag; keine datumslosen/overdue-Carryover).
- Create: `app/api/todos/range/route.ts` -- `GET ?start=&end=` -> `{ days: { [date]: TodoInstance[] } }`.
- Create: `components/calendar-todos.tsx` -- Client-Bausteine: `AgendaTodoRow` (schlanke
  Checkbox-Zeile), `AgendaTodoCluster` ("Auch heute"-Chips), `DayTodoDots` (Wochen-Punkte).
  Nutzt `TodoCheckbox` + Typen/Helfer aus `lib/todos-view.ts`.
- Modify: `app/page.tsx` -- Todos fetchen (today-View fuer Heute, range fuer Woche),
  in `TodayView`-Agenda einweben + unter der Wochen-Tageszahl Punkte rendern; optimistic
  Toggle via `/api/todos/[id]/complete` (Pattern aus app/todos/page.tsx).

## What this does

- `getRangeView`: laedt Todos+Completions einmal, iteriert Tage [start..end]; pro Tag
  nur Aufgaben, die KONKRET dort liegen: einmalige mit `dueDate === tag` (offen) und
  wiederkehrende mit RRULE-Vorkommen am Tag (done = Completion an dem Tag). Sortiert nach
  scheduledTime/Titel. Datumslose und overdue-Carryover bleiben aussen vor.
- Heute-Agenda: terminierte Aufgaben (scheduledTime gesetzt) als schlanke Zeile im Zeit-
  Raster (52px-Zeitspalte + `○ Titel`, muted, kein Karten-Border). Aufgaben ohne Zeit +
  Ueberfaellige -> ruhige Cluster-Zeile unter der Agenda. Abhaken optimistic, dann Reload.
- Wochen-Raster: unter der Tageszahl (neben Ganztags-Balken) max ~4 farbige Punkte fuer
  offene Aufgaben + "+N"; erledigte ausgeblendet. Nicht-interaktiv (nur Praesenz), Klick
  optional spaeter.
